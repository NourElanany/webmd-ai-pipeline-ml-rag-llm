# Refactoring Plan — WebMD AI Pipeline

## Guiding Principles

- No new features. Behaviour is preserved exactly.
- Every piece of logic lives in exactly one place.
- The GUI imports from domain modules; domain modules never import from the GUI.
- All artifacts (models, vectorizers, plots, chroma index) are persisted to disk and
  loaded on demand — nothing is retrained at dashboard startup.
- Python 3.11, `hatch` build backend, `uv` package manager.
- Source layout: `src/webmd/` (PEP 517 / PEP 660 editable install).

## Critical Bug Fixes Bundled Into the Refactor

1. **TF-IDF not persisted** — `app.py` retrains SVC + LR + both vectorizers from scratch
   every time the NLP tab is opened. Fix: `dl_nlp.py` saves all four artifacts with
   `joblib`; `app.py` loads them.

2. **XGBoost `use_label_encoder=False`** — removed in XGBoost 2.x, raises a TypeError.
   Fix: remove the kwarg in `ml/train.py`.

3. **Ensemble weight comment mismatch** — `evaluate_ensemble` docstring says
   "LSTM 35% + TF-IDF 65%" but code uses 80/20. Fix: correct the docstring.

4. **`app.py` NLP `_clean` is a stripped-down version** of `dl_nlp.py` `clean_text`
   (missing contraction expansions). Fix: single `clean_text()` in `nlp/preprocess.py`
   used everywhere.

**`cli.py` `run_ml()`:**
```python
def run_ml():
    from webmd.data.loader import load_cleaned
    from webmd.ml.features import build_features
    from webmd.ml.train import split_data, build_models, train_all, select_best, save_model
    from webmd.ml.plots import generate_ml_plots
    df = load_cleaned(CLEANED_CSV)
    X, y, le = build_features(df)
    splits = split_data(X, y)
    results = train_all(build_models(), splits)
    best = select_best(results)
    save_model(results[best]["model"], ML_MODEL_PATH)
    generate_ml_plots(results, best, splits, ML_PLOTS_DIR)
```
